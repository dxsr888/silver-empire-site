# 白银编织的国运 🏛️

> 一部中国货币史的多书综述 · 交互式数字长文

一个关于 **中国白银历史** 的深度研究型单页网站。以「白银」为线索，串联起跨越千年的中国货币史与经济史叙事：从白银与全球贸易的建立，到白银本位制的兴衰，再到现代转型与当代启示。

## 📖 内容结构

- **白银的多重面貌** —— 白银七大形态 / 千年的白银时代
- **为什么是白银** —— 白银何以成为中国的货币
- **白银与全球贸易的建立** —— 第一章：从朝贡体系到全球白银流动
- **白银作为货币的兴起** —— 第二章：货币制度的跃迁与"一条鞭法"
- **白银帝国：全球白银** —— 第三章：全球白银流动与明清帝国兴衰
- **白银时代：白银的现代转型** —— 第四章：从银本位到现代货币
- **白银的循环与当代启示** —— 历史的回响
- **图鉴** —— 7×7 白银纹样视觉图鉴
- **书籍注释与文本摘录** —— 研究书目与文献引用

## ✨ 特性

- 📜 **全景时间轴**：横跨千年的白银史可交互浏览
- 🔍 **站内搜索**：全文实时检索，高亮定位
- 📱 **响应式布局**：桌面 / 移动端均适配
- 🎨 **"kami" 设计系统**：东方纸张质感、衬线排版、内嵌 webfont（base64 子集），离线可用
- 📖 **多书综述**：基于多部中国货币史著作的交叉综述，附注释与摘录

## 🚀 运行

无需构建，直接打开：

```bash
# 本地预览（任选其一）
npx serve .
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

或直接将 `index.html` 拖入浏览器即可浏览（推荐本地 HTTP 服务以获得完整体验）。
